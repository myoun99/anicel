## A pre-release version

The Anicel you are using is a **pre-release** version. Updates can change how projects are saved, so **a file saved by an earlier version may not open in a newer one.** As long as you keep using this version without updating, nothing changes.

If a newer version cannot open one of your earlier files, upload it to a file transfer service such as GigaFile, then write **its link** and **the email address the converted file should go to** in **Send Feedback** (in the ⚙ Settings menu). We will convert it to the new format and send it back.

From the official release on, the app converts files saved in an earlier format by itself when it opens them.
