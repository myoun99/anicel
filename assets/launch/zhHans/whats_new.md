## 本版本的变化

## 新功能

- **声音行预设** — 声音行 Fx 列表的最上方新增预设（对白、音乐、音效、环境音）。选中后会一次性为该行加上针对这种声音调好的一组效果（均衡器、压缩器等）；加上之后它们就属于该行，数值可以修改。
- **降噪** — 声音行 Fx 菜单的音频栏新增降噪。用一个数值决定听到多少降噪后的声音；刚添加时为 0，不会改变声音。对 44.1 kHz、96 kHz 的声音也有效。
- **同步到预设** — 在媒体池中点击文件的使用中标记打开的窗口里，新增「同步到预设」。从已经放置的位置中选出与放置预设不同的地方，把开始、长度、适配方式等数值改回预设；用「全部应用」可一次改好所有不同的地方。声音、视频和图像都适用。
- **随画布尺寸适配图像** — 在画布尺寸窗口，以及在画布上调整时的胶囊中，可以用「保持比例拉伸」或「忽略比例拉伸」把图像适配到新画布。默认与以前一样，图像保持原样。
- **多个镜头的画布尺寸** — 选中多个镜头块后改变画布尺寸，所选镜头会一次全部改变，撤销也只需一次。
- **切换图层类型** — 点击图像行的类型图标，可在图像、动画、分镜之间切换该行的类型。该行无法变成的类型显示为不可用。在选中多行的状态下点击，所选的行会全部切换。图层菜单中原有的分镜切换已移到这个按钮。
- **用前沿抽帧** — 把帧块的前沿往后拖，会按拖动的格数抽掉块（1 格为 1、3、5、7…，2 格为 1、4、7…）。在分镜面板中，把镜头的前沿拖过镜头末尾，会删除该镜头。
- **图章间距** — 图章工具的设置新增「间距」，以切下的图块大小为比例，默认为一个图块。
- **赛璐珞导出视频的尺寸** — 导出窗口赛璐珞标签页的视频新增「尺寸」（摄影机、画布），默认为摄影机。
- **XDTS 的对象** — 在摄影表格式中选择 XDTS 后，可在其下方选择要导出的对象（原画、中割）。只选一个时，只导出那一项。

## 改进

- **更轻快的应用** — 减少了预先烘焙播放图像时（绿色带填充期间）操作卡顿、在时间轴上滚动鼠标滚轮或切换图层眼睛时的沉重感，以及每画一笔都要等待图形引擎的情况。带有赛璐珞编号 fx 的镜头、拖动 fx 数值时、打开大型 .anicel 时最后的停顿，以及打开 .tvpp 期间也变得更轻快。
- **选择颜色期间** — 转动轨道，或纸张、背景、底板的色轮时，颜色会即时显示，并在关闭窗口时只记录一次，撤销也只需一次。
- **拖动图章** — 一次拖动排出的一列图章，按一次 Ctrl+Z 即可全部撤销。跨多张赛璐珞的图章在等待窗口后放置。
- **连续填充与拖动图章** — 即使画面短暂停顿，期间经过的区域也会全部填满，图章列也会照原样沿着经过的路径排列。
- **分镜用纸上的摄影机指示** — 跨两个分镜格的摄影机运动，会在每一格写出各自的区间（例如 1f-73f T.B、74f-144f T.B）。只有一格的镜头，会用与摄影表相同的说法写出整个镜头。
- **赛璐珞导出** — 没有名字的分镜块也会用下一个空闲的编号命名文件后导出（项目中的块名保持不变）。按颜色标签筛选时，没有标签的行会从导出列表中去掉。导出窗口的折叠栏一开始就是展开的。
- **铺底面板的视图快捷键** — 铺在底部的摄影表或查看器上，缩放、旋转快捷键同样有效。
- **粘贴到 S 行** — 从普通图层复制的帧不会粘贴到 S 行，从 S 行复制的也不会粘贴到普通图层；这时粘贴按钮会变为不可用。
- **TVPaint 导入** — 当声音文件不在 .tvpp 记录的位置时，会在该文件的文件夹下查找并导入。韩文、假名等图层实例名会按原样导入，图层的混合模式（正片叠底等）也会导入。
- **图形设备停止时** — 在 Windows 上，如果绘制画面的图形设备停止，会弹出窗口让你选择「保存并重新启动」「不保存并退出」或关闭。
- **媒体池滚动条** — 媒体池的滚动条在列表视图和图标视图中都始终显示。
- **工具列表** — 工具设置面板中的工具名显示为一行，放不下时用省略号截短；截短的名字可在工具提示中看到全名。

## 问题修正

- 修正了用撤销把变换框的每一步都撤回后，仍残留更改、选区虚线一直显示为红色的问题。
- 修正了撤销记录达到上限后，拖动图章这类由多步组成的操作无法一次撤销的问题。
- 修正了拖动放置图章时最后一个图章丢失的问题。
- 修正了选中多个块后一起编辑（例如拉长格数）时，选区矩形不跟随块的问题。
- 修正了移动到因编辑而清空了绿色带的帧时，图像虽然显示、绿色带却不再填充的问题。
- 修正了改变画布尺寸使基准点移动时，效果的点（径向模糊的中心、赛璐珞编号的位置等）不跟随图像的问题。
- 修正了拖动模糊数值期间内存每次增加数 GB、删除模糊后也不回落的问题。
- 修正了在导出窗口的预览中切换帧时，下一张图像到来之前显示黑屏，以及新出现的加载圈显示成小点的问题。
- 修正了在导出窗口中把 XDTS 摄影表只选中割时显示为空白画面的问题。
- 修正了开启降噪录音的镜次放置得稍晚、与口型错开的问题。
- 修正了删除多个块的颜色时进度窗口看起来停住的问题，现在百分比会逐步增加。
- 修正了把媒体池列表横向滚到最边上再加宽面板时，栏位和滚动条偏移后留在原处的问题。
- 修正了打开子工具列表时，工具设置面板下方的行（连续填充、渐变等）被截断、滚动也到不了的问题。
