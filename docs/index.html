Anicel

タイムシートから作画、絵コンテ、音声同期まで。手描きアニメーションのための制作ツール。 Exposure sheet, drawing, storyboard and sound in one place — a production tool for hand-drawn animation.

CREATED BY MYOUN

123 456

できること What it does

SHEET

タイムシートExposure sheet

コマ打ちと露出をシート上で直接。オニオンスキン、リピート、コマ送り再生まで、タイミングを見るための道具として設計しています。 Comma timing and exposure edited on the sheet itself, with onion skin, repeats and frame-by-frame playback — built to be read as timing, not as a track list.

BRUSH

作画Drawing

筆圧と傾きに応じるネイティブのブラシエンジン。Photoshop の .abr と CLIP STUDIO の .sut を読み込めます。 A native brush engine that answers to pressure and tilt. Photoshop .abr and CLIP STUDIO .sut brushes import directly.

CONTE

絵コンテStoryboard

ストーリーボードとタイムラインが同じカットを見ています。A4・5コマの用紙にベクターPDFで出力できます。 The board and the timeline look at the same cuts. Prints to the Japanese A4 five-panel sheet as a vector PDF.

SOUND

音声Sound

セリフの録音、ノイズ抑制、シートへの同期。声を録ってそのままタイミングを取れます。 Record dialogue, suppress noise, and lay it against the sheet — timing to a voice without leaving the tool.

EXPORT

出力Export

動画、連番PNG、タイムシート。OS のエンコーダをそのまま使うので、書き出しに外部ツールは要りません。 Video, PNG sequences and the sheet itself. Encoding runs on the operating system's own encoder, so nothing else has to be installed.

EVERYWHERE

同じ一つのソフトOne codebase

Windows・macOS・iPad・Android。机の上でも膝の上でも、同じファイルを同じ道具で開けます。 Windows, macOS, iPad and Android — the same file opened by the same tool at the desk or on your lap.
